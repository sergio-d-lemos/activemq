There are a few example programs demonstrating the [REST](../connectivity/protocols/rest) messaging or [Ajax](../connectivity/ajax) in the [activemq/activemq-web-demo](https://github.com/apache/activemq/tree/main/activemq-web-demo/) module.

Running the Web Samples
-----------------------

We have integrated the Web Samples into the binary distribution.

The steps to running the Web Samples are

*   [Download](../overview/download) a binary distribution
*   [Run the Message Broker](../using-activemq-classic/run-broker) e.g. by running bin/activemq
*   point your browser to [http://localhost:8161/demo](http://localhost:8161/demo)
