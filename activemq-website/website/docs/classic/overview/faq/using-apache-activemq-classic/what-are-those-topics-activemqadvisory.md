 [FAQ](..) > [Using Apache ActiveMQ Classic](.) > [What are those topics ActiveMQ.Advisory](what-are-those-topics-activemqadvisory)


When you look at a broker using [JMX](../../../features/jmx) you will see a number of topics starting with **ActiveMQ.Advisory.**. These are the destinations used by the [Advisory Message](../../../features/message-features/advisory-message) feature of ActiveMQ Classic which allows you to listen to the behaviour of the system.
